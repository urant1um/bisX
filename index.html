Операционная система bisX

bisX Operating System

bisX 操作系统

Низкоуровневое кастомное ядро для архитектуры x86_32. Разработка на Linux, сборка сырых дисковых образов и запуск в QEMU.

Low-level custom kernel for x86_32 architecture. Development on Linux, raw disk image building, and QEMU execution.

面向 x86_32 架构的低级自定义内核。在 Linux 上开发、构建原始磁盘镜像并在 QEMU 中运行。

bash — fedora@localhost
$ qemu-img create -f raw disk.img 24M
Formatting 'disk.img', fmt=raw size=25165824
$ qemu-system-i386 -drive format=raw,file=disk.img
[bisX kernel booting...] Uranie is online!
