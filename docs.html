Документация по сборке и запуску

Руководство по подготовке окружения и эмуляции ядра bisX на базе QEMU в Linux.

1. Инициализация сырого диска

Создание файла образа заданного объема (24МБ):

qemu-img create -f raw disk.img 24M

2. Запуск эмулятора x86_32

Передача образа диска эмулятору QEMU:

qemu-system-i386 -drive format=raw,file=disk.img

3. Исходный код и репозиторий
